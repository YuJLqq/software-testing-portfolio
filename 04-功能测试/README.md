功能测试

一、项目简介

基于 ECShop 电商系统，完成前端购买流程的功能测试，覆盖测试计划制定、需求分析、测试用例设计、缺陷提交和测试总结的完整测试流程。

二、技术栈与工具

\- 测试类型：功能测试

\- 测试方法：等价类划分、边界值分析、场景法

\- 文档工具：Word、Excel

\- 被测系统：ECShop 电商系统

三、项目结构

| 文件 | 说明 |

|------|------|

| `测试计划书.pdf` | 测试计划，包含测试范围、测试策略、资源安排等 |

| `需求规格说明书.pdf` | ECShop 系统需求规格说明 |

| `需求分析.pdf` | 前端购买流程的需求分析 |

| `测试用例 - 前端购买流程.pdf` | 前端购买流程的测试用例 |

| `缺陷报告.pdf` | 测试过程中发现的缺陷记录 |

| `测试总结报告.pdf` | 测试执行后的总结与分析 |

四、项目内容

1\. 测试计划

\- 制定测试计划，明确测试范围、测试目标、测试策略和进度安排。

\- 文件：`测试计划书.pdf`

2\. 需求分析

\- 阅读需求规格说明书，梳理前端购买流程的业务逻辑。

\- 输出需求分析文档，明确测试点。

\- 文件：`需求规格说明书.pdf`、`需求分析.pdf`

3\. 测试用例设计

\- 针对前端购买流程设计测试用例。

\- 使用等价类划分、边界值分析、场景法等方法覆盖正常和异常场景。

\- 文件：`测试用例 - 前端购买流程.pdf`

4\. 缺陷管理

\- 执行测试用例，记录发现的缺陷。

\- 缺陷报告包含缺陷描述、复现步骤、严重程度等信息。

\- 文件：`缺陷报告.pdf`

5\. 测试总结

\- 测试完成后输出测试总结报告，统计用例执行情况和缺陷分布。

\- 文件：`测试总结报告.pdf`

五、项目产出

\- 测试计划书

\- 需求分析文档

\- 前端购买流程测试用例

\- 缺陷报告

\- 测试总结报告

六、说明

本项目为软件测试培训期间完成的功能测试实践项目，重点体现完整的功能测试流程、测试用例设计能力、缺陷管理能力和测试文档编写能力。
