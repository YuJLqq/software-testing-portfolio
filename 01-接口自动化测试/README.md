接口自动化测试
一、项目简介
基于 ECShop 电商系统，完成注册、登录等核心接口的测试用例设计与接口测试执行，覆盖接口文档分析、用例设计、Postman 脚本编写与测试运行全流程。
二、技术栈与工具
接口测试工具：Postman
测试用例设计：等价类划分、边界值分析、场景法
文档与用例管理：PDF
接口类型：HTTP/HTTPS 接口
三、项目内容
1. 接口文档分析
阅读 ECShop 前端接口文档，梳理注册、登录等接口的请求方式、请求参数、响应字段和状态码。
文件：`接口文档.pdf`
2. 测试用例设计
针对注册接口和登录接口，分别编写测试用例设计思路文档。
基于等价类、边界值等方法设计正常场景和异常场景用例。
输出测试用例文档，包含用例编号、前置条件、请求参数、预期结果等字段。
\- 文件：
&#x20; - `接口测试用例设计思路 - 注册接口.pdf`
&#x20; - `接口测试用例编写 - 注册接口.pdf`
&#x20; - `接口测试用例设计思路 - 登录接口.pdf`
&#x20; - `接口测试用例编写 - 登录接口.pdf`
3. Postman 接口测试执行
（1）使用 Postman 创建接口测试集合，配置请求参数、请求头和断言。
（2）对注册、登录接口进行实际调用，验证响应状态码、响应字段和业务逻辑。
（3）导出 Postman 集合和测试运行结果，保留测试执行记录。
\- 文件：
&#x20; - `ECShop.postman\_collection.json`
&#x20; - `ECShop.postman\_test\_run.json`
四、项目产出
\- ECShop 注册、登录接口测试用例（PDF）
\- 接口测试用例设计思路文档（PDF）
\- Postman 接口测试集合（JSON）
\- Postman 测试运行结果（JSON）
五、 如何查看
1. 接口文档：直接打开 `接口文档.pdf` 查看接口定义。
2. 测试用例与设计思路：直接打开对应 PDF 文件。
3. Postman 测试集合：导入 Postman 即可查看接口请求和断言配置。
4. 测试运行结果：导入 Postman 或直接查看 JSON 文件中的运行记录。
六、项目说明
本项目为软件测试培训期间完成的接口测试实践项目，重点体现接口测试流程、用例设计能力和 Postman 工具使用能力。
